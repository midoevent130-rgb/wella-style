Wella Style — نسخة مرتبطة بقاعدة بيانات Supabase

محتويات الحزمة:
- index.html: واجهة المتجر ولوحة إدارة المنتجات المتصلة بـ Supabase.
- images/: صور المنتجات الخمس الأصلية.

طريقة التشغيل:
1) ارفعي مجلد Wella_Style_Store إلى استضافة مواقع ثابتة (مثل Netlify أو GitHub Pages).
2) افتحي الموقع واضغطي "فتح لوحة الإدارة".
3) سجلي الدخول بالبريد الإلكتروني وكلمة مرور حساب المدير الذي أنشأته في Supabase Auth.
4) يمكن للمدير إضافة المنتجات وتعديلها وحذفها. المنتجات النشطة تظهر للزوار.

إعداد Supabase المتوقع:
- Project URL: https://dtswdzfpjksghjlhlwvu.supabase.co
- Public key مضمّن في صفحة المتجر (مفتاح publishable فقط).
- جدول public.products بأعمدة: id, name, code, price, category, sizes_colors, image_path, is_active, created_at.
- تفعيل RLS وسياسة SELECT العامة للمنتجات النشطة، وسياسات الكتابة لحساب المدير UID: f97c3c7c-dd14-45ae-854f-7afab9634f07.
- Storage bucket باسم product-images مع قراءة عامة ورفع/تعديل/حذف للمدير فقط.

تنبيه أمني:
- المفتاح المضمّن Publishable key عام بطبيعته؛ الحماية الفعلية تعتمد على RLS وAuth.
- لا تضعي Secret key أو service_role في ملفات الموقع أو المتصفح.
- يجب تنفيذ سياسات Storage على storage.objects قبل اختبار رفع الصور.
- الطلبات والدفع الإلكتروني غير مربوطين في هذه النسخة؛ أزرار الاستفسار ترسل إلى واتساب. لا تستقبلي مدفوعات إلكترونية حتى يتم ربط بوابة دفع حقيقية.
- لا توجد حتى الآن استضافة منشورة؛ هذه الملفات تحتاج رفعًا إلى خدمة استضافة ليصبح الموقع متاحًا للعملاء.
